# Javascript    

 - When dealing with Javascript use Alpine.js installed as NPM package wherever is possible.
 - Use Alpine.data in favour of x-data and always create a seperate file for each component.  

# Tailwind CSS  

 - When using custom colour, spacing, padding, etc, always use a custom config with specification.  

# Laravel  

 - On Laravel Project, always re use component for form, like input, select, radio button, etc.
 - If not exists component, create it.
